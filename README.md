## 🔧 التثبيت والتشغيل

### 1️⃣ إنشاء بيئة افتراضية (مُوصى به)
```powershell
cd lettersys_project
python -m venv .venv
.\.venv\Scripts\activate
```

### 2️⃣ تثبيت المكتبات
```powershell
pip install -r requirements.txt
```

**المكتبات المثبتة:**
- Django==5.2.18
- openpyxl==3.1.2 (لتصدير Excel)
- Pillow==13.0.0 (لمعالجة الصور)

تقرأ المتطلبات قيود الأمان من `security-constraints.txt`؛ يجب نقل الملفين معًا.
حدّث في بيئة افتراضية جديدة، لا فوق بيئة الخدمة الحيّة، ثم تحقّق من الاختبارات
والمهاجرات والنسخة الاحتياطية وفق [دليل التدشين](docs/LAUNCH_RUNBOOK.md).

### 3️⃣ إعداد قاعدة البيانات
```powershell
python manage.py db_healthcheck
python manage.py migrate
python manage.py db_healthcheck --strict
```

### 4️⃣ إنشاء حساب المشرف
```powershell
python manage.py createsuperuser
```

### 5️⃣ تشغيل الخادم محلياً للتطوير فقط
```powershell
python manage.py runserver
```

هذا يشغّل خادم Django التطويري على `localhost:8000` لهذا الحاسوب فقط؛ لا
يُشغّل خدمة الشبكة ولا يُحدّثها. **خدمة LetterSys المستخدمة بين أجهزة الشبكة
تعمل عبر Waitress/NSSM على المنفذ `1312`**. من جهاز آخر افتح
`http://172.16.2.16:1312`، ولا تشغّل `runserver` بديلاً عنها.

### 6️⃣ فتح نسخة التطوير محلياً
افتح: `http://localhost:8000`

### أيقونة تشغيل خدمة LetterSys الحالية (Windows)

على حاسوب الخادم `172.16.2.16`، أنشئ أيقونة **Start LetterSys Server** مرة واحدة:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_lettersys_server_shortcut.ps1
```

الأيقونة تبدأ خدمة Windows الموجودة `LetterSys` فقط بعد التحقق من أنها نسخة Waitress المهيأة على المنفذ `1312` ضمن `D:\lettersys`. قد يطلب Windows تأكيد المسؤول لتشغيل الخدمة. لا تغيّر قاعدة PostgreSQL أو إعداداتها؛ وبعد ظهور رسالة نجاح افتح أيقونة التطبيق المثبّتة المعتادة.

## 🚀 الميزات الحديثة بالتفصيل

### 1. البحث المباشر (Live Search)
```javascript
// في book_list.html
<input data-live-search="#bookTableBody" ... >
```
- البحث يعمل فوراً عند الكتابة
- Debouncing لتقليل الطلبات (300ms)
- تمييز النتائج بالأصفر

### 2. Progressive Web App (PWA)
```javascript
// التثبيت من المتصفح
// أو من البانر الذي يظهر تلقائياً
```
- تثبيت كتطبيق على الجهاز
- يعمل بدون إنترنت
- إشعارات فورية

### 3. الوضع الليلي (Dark Mode)
```javascript
// زر في Navbar للتبديل
// يحفظ الإعداد تلقائياً
```
- ألوان مريحة للعين
- يعمل في جميع الصفحات
- تبديل سلس

### 4. تصدير التقارير (CSV)
التصدير يمرّ عبر `reports_export` في `core/views/` ويشترك مع صفحة التقارير في
نفس مُصفّي الاستعلام (`_reports_qs`) فلا يتباعد المعروض عن المُصدَّر.
- ترميز UTF-8 بعلامة BOM ليفتح صحيحاً في Excel العربي
- يحترم الفلاتر النشطة (الجهة، المدى الزمني، النوع، الحالة)
- طباعة احترافية من الصفحة نفسها

### مسودة واجهة طاولة الوارد — 2026-10-20
- طاولة الوارد ودفتر الوارد وكشف التسليم تشترك في تنقل واضح وهوية تركوازية RTL؛ التصميم مستلهم من تنظيم [Tabler](https://github.com/tabler/tabler) (Bootstrap 5، MIT)، دون نسخ مكتبته أو إضافة اعتماد أو CDN.
- التنسيق معزول في `static/css/desk.css`، ولا يغيّر صفحة «ما يخصّني اليوم» أو قواعد الصلاحيات والترقيم.
- اختيار الوحدة في كشف التسليم يليه زر «تجهيز الكشف» صراحةً، بدلاً من إعادة تحميل الصفحة بمجرد تغيير الاختيار.
- أعمدة الدفتر وخانات توقيع الكشف ومقاسات A4 محفوظة؛ التنقل وأدوات التجهيز للشاشة فقط. الطباعة لا تسجّل الاستلام.
- هذه مسودة للمراجعة البصرية قبل اعتماد المالك؛ لا تعني نشر التغييرات أو دمجها.
- تحديث كثافة الورق: الموضوع يأخذ 42% من عرض جدول الدفتر و43% من كشف التسليم على الشاشة والطباعة؛ هوامش A4 أصبحت 10 مم بدلاً من 14 مم مع تقليل حشو الصفوف دون تصغير خط الموضوع أو قصّه، والحفاظ على ارتفاع خانة التوقيع 1.4 سم. عدد الصفحات الفعلي يعتمد على طول المواضيع والجهات وإعدادات الطابعة.
- المتابعة في الطاولة أصبحت تبويبات مرتبطة بعنوان الصفحة (`?queue=`) بدلاً من بطاقات مزدحمة؛ لكل تصنيف جدول مستقل يفصل الرقم والموضوع والجهة والحالة والغرض والموعد والإجراء. روابط عدّادات لوحة التحكم تفتح التصنيف نفسه.
- تصفية الدفتر والكشف مشتركة: نوع الكتاب، تاريخ الكتاب، ونطاق شامل لأرقام **سجل القسم الحالي** (طرف واحد أو طرفان). الكتب غير المقيّدة في القسم لا تدخل نطاق أرقامه، حتى لو طابق رقمُ قسمها الأصلي النطاق. أرقام السنوات الموسومة تبقى في سلسلتها وفق `core/numbering.py`.
- النطاق الفعّال يظهر في الورقة، وروابط اختيار الوحدة تحتفظ بالتصفية. «مسح التصفية» يحتفظ بالقسم والوحدة، و«الرجوع لطاولة الوارد» وجهته ثابتة، وزر الطباعة لا يظهر إذا لم توجد نتائج أو كانت المدخلات غير صالحة.
- الدفتر سجل للقيود، والكشف قائمة توقيع لإحالات لم تُوثّق عهدتها؛ بقيا منفصلين وظيفياً بعد مراجعة المالك، مع تنقل موحّد. لا يُشتق الكشف من صفوف الدفتر ولا تسجّل طباعته الاستلام.
- إجراءات كل إحالة في الطاولة موسومة باسم الجهة. «تأكيد الوصول» يحدّث حالة الإحالة بعد تأكيد صريح، أما «تسجيل عهدة» فيوثّق الحيازة والتوقيع. في التفاصيل، الجواب والإجراءات عمودان منفصلان، مع إبقاء حراس الأفعال على الخادم ومؤشر تحميل يحافظ على اسم الإجراء.
