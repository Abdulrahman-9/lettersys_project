هذه الخطوة مطلوبة على الجهاز الماستر فقط — تسمح لـ PostgreSQL بقبول اتصالات الأجهزة التابعة على الشبكة المحلية.
{# ─ خطوة A ─ #}
1
ابحث عن ملف pg_hba.conf
-- Windows (PostgreSQL 15)
C:\Program Files\PostgreSQL\15\data\pg_hba.conf
-- Linux
/etc/postgresql/15/main/pg_hba.conf
{# ─ خطوة B ─ #}
2
أضف السطر التالي في نهاية الملف
host    {{ current_db_name }}    {{ current_db_user }}    192.168.1.0/24    scram-sha-256
غيّر 192.168.1.0/24 ليتطابق مع نطاق شبكتك الفعلية. استخدم scram-sha-256 لـ PostgreSQL 14+ أو md5 للإصدارات الأقدم.
{# ─ خطوة C ─ #}
3
أعد تحميل PostgreSQL (بدون إيقاف الخدمة)
-- Windows (PowerShell كمسؤول)
pg_ctl reload -D "C:\Program Files\PostgreSQL\15\data"
-- Linux
sudo systemctl reload postgresql
{# ─ خطوة D ─ #}
4
أضف عنوان IP الماستر لـ CSRF_TRUSTED_ORIGINS في .env
CSRF_TRUSTED_ORIGINS=http://localhost:8000,http://{{ local_ip }}:8000
مطلوب حتى تقبل Django طلبات POST من الأجهزة التابعة.
{# ─ خطوة E ─ #}
5
تحقق من جدار الحماية (Windows Firewall / UFW)
-- Windows (PowerShell كمسؤول)
New-NetFirewallRule -DisplayName "PostgreSQL LAN" -Direction Inbound -Protocol TCP -LocalPort {{ current_db_port|default:"5432" }} -Action Allow
-- Linux (UFW)
sudo ufw allow from 192.168.1.0/24 to any port {{ current_db_port|default:"5432" }}
